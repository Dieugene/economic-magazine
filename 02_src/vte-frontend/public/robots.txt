# Публичная часть журнала открыта для индексации целиком: научному изданию
# важно, чтобы статьи находились в поиске и в Google Scholar.
#
# Закрыт только JSON API. Обход /backend/ ботами тянет мегабайтные ответы
# (список выпусков со всеми вложенными статьями — 7,2 МБ на один запрос) и
# создаёт ровно ту нагрузку, из-за которой сайт лёг 07.09.2026. Индексировать
# там нечего: те же данные бот видит на обычных страницах.
#
# PDF статей и выпусков раздаются тем же путём (/backend/<ресурс>/<id>/download_pdf/),
# и вот их индексация нужна — поэтому они открыты поимённо. Правило Allow
# длиннее правила Disallow, поэтому у Google и Яндекса выигрывает именно оно.
#
# Каталог админки здесь намеренно НЕ упоминается: robots.txt читают все, и
# строка Disallow опубликовала бы её адрес тем, кто ищет панель входа.
User-agent: *
Disallow: /backend/
Allow: /backend/articles/*/download_pdf/
Allow: /backend/issues/*/download_pdf/
